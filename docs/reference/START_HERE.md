## Архитектура

React + Vite + TypeScript. Модульная организация по секциям страницы и интерактивным features. Состояние локально рядом с поведением; глобальный state manager для этой задачи не нужен.

```text
src/
  app/
    App.tsx
    global.scss
  content/
    profile.ts
    projects.ts
    types.ts
  sections/
    intro/
    about/
    engineering/
    projects/
    case-studies/
  features/
    loyalty-demo/
    project-gallery/
    booking-demo/
    report-calculator/
  shared/
    ui/
    hooks/
public/
  images/
```

- app: собирает страницу, глобальные стили, общие переменные.
- content: тексты и данные, без JSX.
- sections: композиция блоков.
- features: самостоятельные взаимодействия и hooks.
- shared: реально переиспользуемые компоненты/hooks.
- Для компонентов использовать ComponentName.module.scss. Допустим отдельный global.scss для reset и токенов.
- Основные компоненты секций экспортировать именованно, без обязательных props, если используют центральные данные.

Зафиксированный контракт Project уже есть в коде:
