# Buianto Shagdurov — Product Atlas

Англоязычная персональная визитка: опыт, стек и интерактивные кейсы в PropTech, TravelTech и промышленной аналитике.

## Запуск

Требуется Node.js, совместимый с установленным Vite 8 (20.19+ или 22.12+), и npm.

```sh
npm ci
npm run dev
```

Для локального просмотра production-сборки:

```sh
npm run build
npm run preview
```

## Проверки

```sh
npm run typecheck
npm run lint
npm run build
```

Компонентные тесты и тестовая инфраструктура намеренно не добавлены. Браузерные сценарии и результаты описаны в [отчёте проверки](docs/verification.md).

## Устройство проекта

- `src/app` — композиция страницы, reset и глобальные токены.
- `src/content` — профиль, проекты и исходный контракт Project.
- `src/sections` — Intro, About, инженерный блок, галерея и case notes.
- `src/features` — Loyalty pass, галерея, booking demo и калькулятор отчётов.
- `src/shared/hooks` — media queries и однократное появление секции.
- `public/images` — оптимизированные WebP из исходного референса.

Стили компонентов находятся в `{ComponentName}.module.scss`. Используется системный шрифт без внешних загрузок. Роутер, backend и глобальный state manager не нужны.

## Взаимодействия

- Loyalty pass: три этапа сделки, replay и независимое раскрытие четырёх слоёв архитектуры.
- Галерея: прокрутка и кнопки выбора; при reduced motion или высоте viewport до 500 px — обычная секция с кнопками.
- Case notes: нативные details; прямые hash-ссылки раскрывают соответствующий кейс.
- Booking: упрощённые Before/After сценарии, сброс при смене варианта и replay.
- Reports: 1–20 отчётов, экономия 105 минут на отчёт.

Демонстрации иллюстративные, работают в браузере без запросов к продуктовым API. Они не воспроизводят закрытые интерфейсы и реальные правила продуктов.
