# План реализации Product Atlas

Дата: 11 ноября 2026. Цель: перенести статическую визитку Buianto Shagdurov в существующий React + Vite + TypeScript проект, сохранив содержание и интерактивность.

## Ограничения и исходное состояние

- Локальный Vite-проект уже существовал; npm, React, TypeScript и Vite сохраняются.
- До изменений `npm run build` и `npm run lint` проходили.
- Работа выполняется в ветке `codex/react-portfolio`, без pull, push, PR и публикации.
- Системный шрифт, тёмный фон, крупная типографика, зелёный акцент.
- Стили компонентов: только `{ComponentName}.module.scss`; reset и токены: `global.scss`.
- Данные централизованы, состояние локально; backend, роутер и глобальный state manager не нужны.
- Компонентные тесты и тестовая инфраструктура не нужны. Обязательны typecheck, lint, build и браузерная проверка.
- Демонстрации иллюстративные: реальные данные, балансы и интерфейсы продуктов не воспроизводятся.
- Работа последовательная, без субагентов.
